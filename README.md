# 🐱 도트냥 할 일 (DotCat Todo)

> **"늦은 밤, 보라색 조명 아래 고양이와 함께 로파이 음악을 들으며 할 일을 정리하는 책상"**  
> 나 혼자 쓰는, 귀엽고 따뜻한 감성의 도트 고양이 할 일 웹 앱(PWA)입니다.

---

## ✨ 주요 특징

* 🎨 **로파이 밤보라 테마**: 채도를 낮춘 따뜻하고 포근한 밤보라 다크 테마 및 CRT 모니터 스캔라인 효과
* 🐾 **7가지 감정 반응형 도트 고양이 (도트냥)**:
  * `낮잠 (sleep)`: 오늘 할 일이 0개일 때 동그랗게 웅크려 잠 (`zzz`)
  * `기다림 (waiting)`: 시작 전 꼬리를 살랑살랑 흔들며 응원 대기
  * `응원 (cheer)`: 1개 이상 완료 시 앞발을 번쩍 들어 응원
  * `신남 (excited)`: 50% 이상 완료 시 들썩들썩 신난 댄스
  * `대성공 (celebrate)`: 오늘 할 일 모두 완료 시 하트와 점프 축하 댄스!
  * `깜짝 (shocked)`: 기한 지난 할 일이 있을 때 느낌표(`!`)와 곤두선 털
  * `밤 (night)`: 밤 11시 이후 게슴츠레 졸린 눈
  * **쓰다듬기 인터랙션**: 고양이를 클릭하면 귀여운 야옹 소리와 함께 하트 파티클 & 애교 말풍선 출력!
* 🎵 **8-Bit 레트로 사운드 엔진**: Web Audio API로 구현되어 외부 음원 파일 의존 없이 도장 쿵! 소리, 완료 팡파레, 레트로 벨소리 제공 (설정에서 On/Off 가능)
* 📅 **인터랙티브 픽셀 미니 달력 & 시간 설정**:
  * 월별 달력에서 날짜를 클릭하여 원클릭 마감일 지정
  * 원하는 시간(`HH:mm`) 및 빠른 시간 버튼(오전 9시, 오후 1시, 저녁 6시, 밤 9시, 마감 23:59) 지원
* ⚡ **5초 빠른 추가**: 항상 노출되는 입력창에서 제목 입력 후 Enter를 치면 즉시 등록 및 연속 입력 포커스 유지
* 🔄 **실행 취소 (Undo)**: 삭제 후 5초간 화면 하단에 실행 취소 토스트 배너 제공 (소프트 삭제 및 30일 보관 휴지통)
* 💾 **완벽한 오프라인 영속성 & 백업**: 브라우저 로컬 저장소(LocalStorage) 기반 동작, 원클릭 JSON 백업 다운로드 및 자동 백업 스냅샷 롤백 기능
* 📱 **PWA (Progressive Web App)**: 모바일/PC 홈 화면에 앱으로 설치하여 단독 창으로 실행 가능

## 📂 프로젝트 구조

```
todolist/
├── index.html                 # 메인 웹 페이지
├── manifest.json              # PWA 매니페스트 설정
├── sw.js                      # PWA 오프라인 캐시 서비스 워커
├── .gitignore                 # Git 제외 파일 목록
├── README.md                  # 프로젝트 설명서
├── css/
│   ├── pixel-base.css         # 테마 변수, 폰트, 리셋, 스캔라인
│   ├── cat.css                # 도트 고양이 룸 & 7가지 감정 애니메이션
│   ├── layout.css             # PC 3단 / 모바일 바텀시트 반응형 레이아웃
│   └── components.css         # 픽셀 달력, 버튼, 카드, 도장 체크박스, 토스트
├── js/
│   ├── icons.js               # 픽셀 SVG 아이콘 모음
│   ├── sound.js               # 8비트 치프튠 사운드 신시사이저 (Web Audio API)
│   ├── store.js               # 로컬스토리지 데이터 관리, Undo, JSON 백업/복원
│   ├── cat.js                 # 고양이 상태 머신, 말풍선 대사, 파티클
│   ├── ui.js                  # 뷰 렌더링, 달력/시간 피커, 인터랙션
│   ├── app.js                 # 메인 앱 초기화, 단축키, 시간 감지
│   └── pwa.js                 # PWA 설치 프로프트 및 네트워크 감지
└── assets/
    ├── icon-192.svg           # 앱 아이콘 (192x192)
    └── icon-512.svg           # 앱 아이콘 (512x512)
```

## 🚀 실행 방법

별도의 Node.js 설치나 빌드 과정 없이 바로 사용할 수 있습니다.

1. 이 저장소를 다운로드하거나 클론합니다.
2. `todolist` 폴더 안의 `index.html` 파일을 웹 브라우저(Chrome, Edge, Whale, Safari 등)로 더블클릭하여 엽니다.
3. GitHub Pages, Vercel, Netlify 등에 폴더 채로 업로드하면 즉시 온라인 웹앱으로도 사용하실 수 있습니다.
