# 할 일 목록(To Do) 프로그램 PRD

버전 0.2 (개인용 개정) · 작성일 2026-10-30

## 6. 데이터 모델 (초안)

## 1. 개요: 무엇을 만드는가

나 혼자 쓰는, 폰과 PC에서 같은 목록이 열리는 **귀여운 도트 고양이 할 일 앱**을 만든다. 로그인·공유·협업 없이 "빨리 적고, 오늘 할 일만 보고, 끝내면 기분 좋은" 것에 집중한다.

**만드는 이유**

- 할 일을 메모장, 카톡, 머릿속에 흩어 두면 누락된다.
- 기존 앱은 기능이 많아 쓰기 시작하는 것 자체가 부담이다.
- 내가 좋아하는 분위기(도트, 고양이, 보라색, 로파이)의 앱이면 매일 열고 싶어진다. **디자인이 습관을 만드는 장치**다.

**제품 목표**

1. 할 일 하나를 **5초 안에** 추가한다.
2. 오늘 할 일을 **한 화면**에서 확인한다.
3. 폰에서 적은 것이 PC에, PC에서 적은 것이 폰에 **몇 초 안에** 보인다.
4. 완료할 때 작은 보상(고양이 반응)이 있어 매일 열게 된다.

**비목표 (이번 버전에서 하지 않는 것)**

- 회원가입, 소셜 로그인, 다른 사람과의 공유·협업
- 외부 캘린더(구글, 네이버) 양방향 연동
- 앱스토어 배포용 네이티브 앱 (대신 홈 화면에 추가하는 웹앱 PWA)
- AI 자동 일정 추천

**성공 기준 (개인용이므로 단순하게)**

| 기준 | 목표 |
| --- | --- |
| 할 일 추가 소요 시간 | 5초 이하 |
| 2주 연속 사용 | 하루 1회 이상 앱을 연다 |
| 동기화 지연 | 온라인에서 3초 이내 |
| 데이터 유실 | 0건 (백업 가능) |

## 2. 사용 상황: 누가, 언제, 어디서 쓰는가

사용자는 **나 한 명**이고, 기기는 **폰(주로 이동 중·한 손)** 과 **PC(주로 공부·작업 중·키보드)** 두 가지다. 그래서 폰에서는 "빨리 적기와 체크", PC에서는 "정리와 한눈에 보기"를 중심으로 설계한다.

| 상황 | 기기 | 하는 일 | 설계 포인트 |
| --- | --- | --- | --- |
| 아침 | 폰 | 오늘 할 일 확인, 우선순위 정하기 | 홈 화면 첫 화면에 '오늘'만 표시 |
| 수업·이동 중 | 폰 | 갑자기 생긴 할 일 메모, 마감 있는 과제 추가 | 하단 입력창, 한 손 조작, 마감일 빠른 선택(오늘/내일/이번 주) |
| 공부·작업 중 | PC | 목록 정리, 과제 나누기, 키보드로 연속 입력 | 단축키, 하위 할 일, 사이드바 |
| 저녁 | 폰/PC | 완료 체크, 못 끝낸 일 내일로 미루기 | 일괄 '내일로 옮기기' |
| 주말 | PC | 한 주 돌아보기 | 주간 통계 (2차) |

**전제**

- 두 기기를 **동시에 쓰는 일은 드물지만** 번갈아 쓰는 일은 잦다. 따라서 실시간 공동 편집보다 "열었을 때 최신 상태"가 중요하다.
- 인터넷이 끊겨도(지하철, 강의실) 적을 수 있어야 한다.

## 3. 디자인 콘셉트: 도트 고양이 + 보라색 + 로파이

**한 줄 콘셉트**: 늦은 밤, 보라색 조명 아래 고양이와 함께 로파이 음악을 들으며 할 일을 정리하는 책상.

**키워드**: 도트(픽셀 아트) · 고양이 · 보라색 · 로파이(낮은 채도, 포근함) · 귀여움

### 3.1 색상

로파이 느낌을 위해 **채도를 낮춘 보라 계열**을 기본으로 하고, 포인트만 밝게 쓴다. (색상값은 시작점이며 실제 화면에서 조정한다.)

| 용도 | 이름 | 색상값 | 쓰는 곳 |
| --- | --- | --- | --- |
| 배경 | 밤보라 | #1E1633 | 앱 전체 배경 |
| 카드 | 어스름 | #2D2347 | 할 일 카드, 입력창 |
| 기본 포인트 | 라벤더 | #B794F6 | 버튼, 선택된 탭, 진행 바 |
| 보조 | 연라일락 | #D6C6FF | 제목, 아이콘 |
| 따뜻한 강조 | 크림 | #FFF3D6 | 본문 글자, 고양이 털 |
| 귀여운 강조 | 분홍 | #FF9EC7 | 우선순위 높음, 하트 |
| 완료 | 민트 | #8FE3C0 | 체크, 완료 표시 |
| 경고 | 산호 | #FF7A8A | 기한 지남 |

- 본문 글자(크림)와 배경(밤보라)의 대비는 읽기에 충분하게 유지한다(대비비 4.5:1 이상 확인).
- 라이트 모드는 만들지 않고 **보라 다크 테마 하나**로 간다. 범위가 줄고 콘셉트가 선명해진다. (낮에 보기 불편하면 '낮 보라' 모드를 2차로 검토)

### 3.2 글꼴과 그래픽

- **글꼴**: 한글 도트 글꼴을 제목과 버튼에 쓴다. 후보는 갈무리(Galmuri), 둥근모꼴(DungGeunMo)이며 **라이선스를 확인**한다. 긴 본문과 메모는 읽기 편하도록 일반 산세리프를 섞는 것을 권한다.
- **그래픽**: 16x16 또는 32x32 픽셀 스프라이트. 화면에서 확대할 때 **이미지 보간을 끄고**(image-rendering: pixelated) 도트가 뭉개지지 않게 한다.
- **모서리와 그림자**: 둥근 모서리 대신 **계단형 픽셀 테두리**와 1\~2px 단단한 그림자를 쓴다.
- **로파이 질감**: 아주 약한 필름 그레인과 스캔라인(투명도 5% 안팎). 글자 가독성을 해치면 끌 수 있게 설정에 둔다.

### 3.3 고양이 마스코트 (가칭)

홈 화면 상단에 고양이가 살고, **오늘의 할 일 상태에 따라 모습이 바뀐다.** 이것이 이 앱의 가장 큰 개성이자 매일 여는 이유다.

| 상태 | 조건 | 고양이 모습 |
| --- | --- | --- |
| 낮잠 | 오늘 할 일이 0개 | 동그랗게 웅크려 잔다 (zzz) |
| 기다림 | 할 일이 있고 아직 시작 전 | 앉아서 꼬리만 살랑 |
| 응원 | 1개 이상 완료, 절반 미만 | 앞발을 들어 응원 |
| 신남 | 절반 이상 완료 | 몸을 흔들며 걷는다 |
| 대성공 | 오늘 할 일 모두 완료 | 춤추고 하트가 올라온다 |
| 깜짝 | 기한이 지난 할 일이 있음 | 털이 곤두서고 느낌표 |
| 밤 | 밤 11시 이후 | 눈을 반쯤 감고 졸고 있다 |

**완료 피드백**: 체크하면 체크박스가 픽셀 도장처럼 찍히고 작은 효과음(끌 수 있음)과 별 모양 파티클이 나온다.

**보상 요소 (2차)**: 할 일을 완료할 때마다 '츄르'가 쌓이고, 모은 츄르로 고양이에게 모자, 목도리 같은 아이템을 입힌다.

### 3.4 로파이 요소 (2차)

- **집중 타이머**: 25분 집중 + 5분 휴식. 타이머가 도는 동안 고양이가 책상에서 같이 공부한다.
- **배경 사운드**: 비 오는 소리 같은 백색소음 켜기/끄기. **음원은 직접 만든 것이나 저작권 걱정이 없는 것만** 사용한다.
- **창밖 장면**: 시간대에 따라 창밖 색(저녁 노을, 밤하늘)이 바뀐다.

### 3.5 디자인 원칙

1. **귀여움은 장식이 아니라 반응**이다. 고양이가 움직이는 건 의미(상태)가 있을 때만.
2. **읽기 편함이 먼저**다. 도트 글꼴은 짧은 글자에만 쓰고 목록은 읽기 쉽게.
3. **움직임 줄이기 설정**을 존중한다. 기기 설정에서 동작 줄이기를 켜면 애니메이션을 정지 이미지로 대체한다.

## 5. 화면 구성: 5개 (이후 확장 시 7개)

로그인 화면이 없어져 **MVP는 5개 화면**이다. 폰은 하단 탭, PC는 왼쪽 사이드바로 같은 화면 구조를 다르게 배치한다.

| # | 화면 | 시점 | 역할 |
| --- | --- | --- | --- |
| 1 | 홈 (오늘) | MVP | 고양이, 달성률, 기한 지난 항목, 오늘 할 일, 빠른 입력창 |
| 2 | 전체 목록 | MVP | 인박스·예정·완료·휴지통과 사용자 목록별 보기, 검색·필터·정렬 |
| 3 | 할 일 상세 | MVP | 제목, 메모, 마감일, 우선순위, 목록, 하위 할 일, 반복, 알림 |
| 4 | 목록 관리 | MVP | 목록 만들기, 이름·색상 변경, 순서, 삭제 |
| 5 | 설정 | MVP | 동기화 상태, 백업(내보내기/가져오기), 알림, 효과음·애니메이션·스캔라인, 하루 시작 시각 |
| 6 | 통계 | 이후 | 주간·월간 완료 수, 목록별 비율, 연속 달성 |
| 7 | 캘린더 | 이후 | 월간 마감일 분포 |

**보조 UI (별도 화면으로 세지 않음)**: 빠른 추가 시트(폰 하단에서 올라옴), 날짜 선택기, 삭제 '되돌리기' 토스트, 알림 권한 안내, 첫 실행 안내(예시 할 일 2\~3개), 동기화 충돌 안내.

### 5.1 화면 이동

```
홈(오늘) ─┬─ 전체 목록 ── 할 일 상세
          ├─ (이후) 통계 · 캘린더
          └─ 설정 ── 목록 관리
빠른 추가는 모든 화면에서 + 버튼 또는 N 키로 열린다
```

- **폰**: 하단 탭 3개(홈, 전체, 설정) + 중앙 ⊕ 추가 버튼. 엄지 손이 닿는 위치에 입력이 오도록 한다.
- **PC**: 왼쪽 사이드바(목록과 보기), 가운데 목록, 오른쪽에 상세 패널(3단 구성). 상세를 열어도 목록이 사라지지 않는다.

### 5.2 화면별 핵심 요소

**홈 (오늘)**

- 맨 위: 고양이와 말풍선(예: "오늘 3개 남았다냥"), 오늘 달성률 바
- 그 아래: 기한 지난 항목(접기 가능, 일괄 처리 버튼), 오늘 할 일 목록
- 맨 아래: 항상 보이는 빠른 입력창
- 비었을 때: 고양이가 낮잠을 자고 "오늘은 쉬어도 좋아"라고 보여준다

**전체 목록**

- 위: 검색창, 필터·정렬 버튼
- 목록 구분(탭 또는 사이드바): 인박스 · 예정 · 사용자 목록들 · 완료 · 휴지통
- 항목: 체크박스, 제목, 마감일 배지(오늘=라벤더, 지남=산호), 우선순위 색 점

**할 일 상세**

- 폰은 아래에서 올라오는 시트, PC는 오른쪽 패널
- 모든 변경은 자동 저장되고, 저장 중/완료 상태는 작은 아이콘으로만 표시

**설정**

- 맨 위에 동기화 상태(마지막 동기화 시각, 대기 중인 변경 수)를 둬서 **"데이터가 안전한가"를 바로 확인**할 수 있게 한다.

### 5.3 모든 화면에 정의할 상태

빈 상태, 로딩 상태, 오류 상태(다시 시도), 오프라인 상태를 **각 화면마다** 정해 둔다. 특히 빈 상태는 고양이 그림으로 채운다.

## 6. 데이터와 동기화

개인용이지만 **폰과 PC를 오가기 때문에 데이터 설계가 이 앱의 핵심**이다. 기본 방식은 "기기에 먼저 저장하고(오프라인 우선), 연결되면 서버와 맞춘다"이다.

### 6.1 저장 데이터

| 데이터 | 주요 항목 |
| --- | --- |
| Task(할 일) | id, 제목, 메모, 마감일시(선택), 우선순위(0\~2), 상태(미완료/완료), 완료일시, 목록 id(선택), 반복 규칙(선택), 정렬 순서, 생성·수정·삭제 일시 |
| Subtask(하위 할 일) | id, task id, 제목, 완료 여부, 정렬 순서 |
| List(목록) | id, 이름, 색상, 정렬 순서 |
| Settings(설정) | 효과음, 애니메이션, 스캔라인, 하루 시작 시각, 한 주 시작 요일 |
| Cat(고양이, 2차) | 츄르 수, 보유 아이템, 착용 아이템 |

### 6.2 데이터 규칙

- **id는 기기에서 직접 만든 고유값(UUID)** 으로 한다. 오프라인에서 추가해도 id가 겹치지 않는다.
- **삭제는 '삭제됨 표시'(소프트 삭제)** 로 처리한다. 다른 기기에 삭제 사실을 전달해야 하고, 휴지통 복구도 가능하다.
- **시간은 UTC로 저장**하고 화면에서는 한국 시간(KST)으로 보여준다. 마감일만 있는 항목(시간 없음)은 날짜로만 저장해서 시간대에 따라 하루가 밀리지 않게 한다.
- **저장 형식 버전(schemaVersion)** 을 데이터에 넣어 둔다. 나중에 항목을 추가해도 예전 백업 파일을 불러올 수 있다.
- 모든 항목에 **수정 일시**를 기록해 어느 쪽이 더 최근인지 비교한다.

### 6.3 동기화 방식

1. 모든 변경은 **먼저 기기의 로컬 저장소에 즉시 저장**한다(화면이 서버를 기다리지 않는다).
2. 연결되어 있으면 **변경분만** 서버로 보내고, 서버의 새 변경을 받아 온다.
3. 두 기기가 같은 항목을 고쳤다면 **항목 단위로 수정 일시가 더 최근인 쪽을 채택**한다(마지막 수정 우선). 덮어쓰인 내용은 설정의 '충돌 기록'에 남겨 복구할 수 있게 한다.
4. 연결이 끊기면 변경을 대기열에 쌓고 **대기 중 N개**를 설정에 표시한다.
5. 앱을 다시 열거나 화면이 다시 보일 때 즉시 한 번 동기화한다.

### 6.4 백업과 복구 (개인용에서 가장 중요)

서버가 없거나 브라우저 데이터를 지우면 할 일이 통째로 사라질 수 있다. 그래서 다음을 **MVP에 포함**한다.

- 설정에서 **JSON 내보내기**(한 번에 파일 하나)와 **가져오기**
- 가져오기 전에 **현재 데이터를 자동으로 내보내기 백업**
- 동기화를 쓰더라도 주 1회 정도 내보내기를 권하는 안내(설정 화면)
- 휴지통 30일 보관

## 7. 기술 구성과 배포

**핵심 결정: 폰과 PC를 동기화하려면 서버(클라우드 저장소)가 필요하고, 서버에 데이터를 두면 '나만 열 수 있게' 잠그는 최소한의 로그인(본인 계정 1개)이 필요하다.** 다른 사람을 위한 회원가입·비밀번호 찾기 같은 기능은 만들지 않는다.

### 7.1 단계별 구현 (권장)

한 번에 다 만들면 지치기 쉬워서, **혼자 쓸 수 있는 상태를 빨리 만들고 점점 얹는 순서**를 권한다.

| 단계 | 구성 | 얻는 것 |
| --- | --- | --- |
| 1단계 | HTML + CSS + JavaScript, 데이터는 브라우저 저장소(IndexedDB 또는 localStorage), JSON 내보내기/가져오기 | 한 기기에서 완전히 동작하는 앱, 도트 디자인과 고양이 완성 |
| 2단계 | PWA 적용(홈 화면 설치, 오프라인 동작), 배포 | 폰과 PC에서 앱처럼 열기 (이 단계까지는 기기 간 자동 동기화 없음, 내보내기/가져오기로 옮김) |
| 3단계 | 클라우드 저장소와 본인 1인 로그인 추가, 자동 동기화 | 폰과 PC 자동 동기화 |
| 4단계 | 푸시 알림, 고양이 꾸미기, 타이머, 통계 | 매일 쓰게 만드는 요소 |

### 7.2 클라우드 저장소 후보 (3단계 때 선택)

| 후보 | 장점 | 고려할 점 |
| --- | --- | --- |
| Supabase | 데이터베이스와 로그인이 한 곳에 있고 실시간 변경 수신이 가능 | 설정 개념(보안 규칙)을 익혀야 함 |
| Firebase | 자료가 많고 오프라인 동기화 기능이 기본 제공 | 데이터 구조가 서비스에 종속되는 편 |
| 직접 파일 동기화(JSON을 클라우드 드라이브에 저장) | 서버 지식이 거의 필요 없음 | 충돌 처리와 자동화가 번거로움 |

무료 요금제의 한도와 정책은 바뀔 수 있으니 **선택하기 직전에 공식 문서로 확인**한다. 개인용 할 일 수천 건 정도는 대부분 문제없는 규모다.

### 7.3 배포

- GitHub Pages, Netlify, Vercel, Cloudflare Pages 중 하나에 올리면 폰에서도 같은 주소로 열 수 있다. 정적 웹앱이라 비용이 거의 들지 않는다.
- 코드는 GitHub에 올려 변경 이력을 남긴다.
- **HTTPS 필수**(PWA와 알림 조건).

### 7.4 개인 보안 최소 기준

- 로그인은 본인 이메일 1개만 허용(가입 기능은 막아 둔다).
- 서버 저장소는 **로그인한 본인만 읽고 쓰도록 규칙을 반드시 설정**한다(이 설정을 빠뜨리면 데이터가 공개될 수 있다).
- API 키 중 공개용이 아닌 비밀 키는 앱 코드에 넣지 않는다.
- 할 일에 민감한 정보(비밀번호, 계좌번호)는 적지 않는 것을 원칙으로 한다.

## 8. 놓치기 쉬운 부분

### 8.1 비기능 요구사항

| 항목 | 요구사항 |
| --- | --- |
| 속도 | 앱 실행 후 2초 안에 오늘 목록 표시, 할 일 1,000개에서도 스크롤이 끊기지 않음 |
| 화면 크기 | 폰(360px)부터 PC(1440px)까지. 폰 우선 설계 |
| 터치와 키보드 | 폰은 한 손 조작(주요 버튼 하단), PC는 키보드만으로 모든 조작 가능 |
| 접근성 | 글자 대비 4.5:1 이상, 색만으로 상태를 구분하지 않음(아이콘·글자 병행), 동작 줄이기 설정 존중 |
| 오프라인 | 인터넷 없이 실행·추가·수정·완료 가능 |
| 도트 표현 | 확대·고해상도 화면에서도 도트가 흐려지지 않음 |
| 호환성 | 최신 Chrome, Safari(iOS), Edge, 삼성 인터넷 |

### 8.2 입력과 데이터

- 제목이 비면 추가하지 않고 입력창을 살짝 흔들어 알려준다.
- 제목은 200자까지, 목록에서는 말줄임 처리한다.
- 같은 제목 중복은 허용한다(반복되는 일이 흔하다).
- 마감일을 과거로 지정하면 경고만 하고 허용한다.
- 이모지, 긴 링크, 줄바꿈이 들어와도 화면이 깨지지 않는다.

### 8.3 날짜와 반복

- **'오늘'의 기준**: 새벽 1시에 쓰는 일이 잦다면 자정이 아니라 **설정한 하루 시작 시각(예: 새벽 4시)** 을 기준으로 오늘을 계산한다.
- 매월 31일 반복인데 그 달에 31일이 없으면 **말일**로 처리한다.
- 반복 할 일을 지울 때는 "이번 것만 / 앞으로 모두"를 묻는다.
- 반복 할 일을 며칠 미완료로 두면 쌓이지 않고 **가장 최근 회차 하나만** 남겨 둔다(안 그러면 목록이 빨갛게 넘친다).

### 8.4 완료와 미룸

- 완료 취소가 쉬워야 한다(실수 방지).
- 기한 지난 항목이 계속 쌓이면 앱이 부담스러워진다. **일괄 처리 버튼**과 부드러운 문구("괜찮아, 다시 잡아보자")를 쓴다.
- 완료한 항목은 30일 후 '완료 보관함'으로 옮기되 통계에는 계속 반영한다.

### 8.5 동기화 상황

- 폰에서 오프라인으로 고친 항목을 PC에서도 고쳤다면 6.3의 규칙대로 최근 수정이 이기고, 졌던 내용은 충돌 기록에 남는다.
- 한 기기에서 삭제한 항목을 다른 기기가 오프라인에서 수정했다면 **삭제보다 수정을 우선해 복원**한다(할 일이 조용히 사라지는 것이 더 나쁘다).
- 브라우저 데이터가 지워진 새 기기에서 앱을 열면 서버에서 전체를 내려받는다. 이때 로딩 화면(고양이가 뛰어다니는 연출)을 보여준다.

### 8.6 알림

- 알림 권한을 거부했을 때 설정에서 다시 켜는 방법을 안내한다.
- 하루 알림 횟수에 상한을 둬서 알림 피로를 막는다.
- **아이폰에서는 홈 화면에 설치한 웹앱에서만 푸시가 동작하는 등 제약이 있으므로** 4단계 전에 사용 중인 기기에서 먼저 테스트한다.

### 8.7 처음 실행

- 빈 화면 대신 **고양이 인사와 예시 할 일 2\~3개**를 보여주고, 지우는 방법을 알려준다.
- 기본 목록은 '인박스' 하나만 만든다.

### 8.8 저작권과 자산

- 도트 이미지와 효과음, 글꼴은 **직접 제작하거나 사용 허가가 분명한 자료**만 쓴다. 인터넷의 캐릭터 이미지나 음원을 가져오지 않는다.
- 글꼴은 라이선스(상업적 이용, 배포 조건)를 확인하고 출처를 기록한다.

## 9. 로드맵, 리스크, 결정할 것

### 9.1 로드맵

4장의 P0 기능은 **단계 1\~3을 모두 마쳐야** 완성된다. 단계 1만 끝나도 한 기기에서는 바로 쓸 수 있으니, 거기서부터 실제로 써 보면서 다음 단계를 진행한다. 기간은 하루 1\~2시간 작업을 가정한 **대략의 가늠**이다.

| 단계 | 범위 | 끝났다고 보는 기준 | 가늠 |
| --- | --- | --- | --- |
| 0. 준비 | 와이어프레임(손그림 가능) 5장, 고양이 스프라이트 상태별 초안, 색상·글꼴 확정 | 화면 5개의 배치와 고양이 7가지 모습 초안이 있다 | 3\~5일 |
| 1. 한 기기 완성 | F-01\~07, F-11, F-20\~22, F-30\~31, F-40, F-52, 로컬 저장 | 내가 폰 또는 PC 한쪽에서 일주일간 실제로 쓸 수 있다 | 2\~3주 |
| 2. 앱처럼 쓰기 | PWA 설치, 오프라인 동작, 배포, F-54 | 폰 홈 화면에서 앱처럼 열리고 비행기 모드에서도 추가된다 | 3\~5일 |
| 3. 동기화 | 클라우드 저장소, 본인 1인 로그인, F-50\~51 | 폰에서 적은 것이 PC에 3초 안에 보이고, 오프라인 변경도 합쳐진다 | 1\~2주 |
| 4. 편의 확장 | P1 기능(상세 메모, 하위 할 일, 반복, 검색, 단축키, 푸시 알림) | 반복 할 일과 알림이 안정적으로 동작한다 | 2\~4주 |
| 5. 즐거움 확장 | P2 기능(츄르·꾸미기, 집중 타이머, 통계, 자연어 입력) | 고양이 꾸미기와 타이머를 쓸 수 있다 | 자유 |

### 9.3 결정해야 할 것

1. **서버를 쓸 시점**: 단계 1\~2(한 기기 + 설치)부터 쓰다가 나중에 동기화를 붙일지, 처음부터 동기화를 넣을지
2. **클라우드 저장소**: Supabase, Firebase 중 무엇으로 할지 (단계 3 직전에 결정해도 된다)
3. **고양이 도안**: 직접 그릴지, 도트 도구로 만들지, 의뢰할지 (저작권이 명확해야 함)
4. **하루 시작 시각**: 자정, 아니면 새벽 4시 같은 별도 기준
5. **앱 이름**: 가칭을 정하면 화면과 아이콘 작업이 쉬워진다
6. **밝은 테마 필요 여부**: 보라 다크 하나로 갈지
